# Little means a Lot, a Simple Bakery Game

A game made in *Unity*, where you start by making *bread* and slowly being able to buy ingredients for a *cake*. You just sell the product to afford better ingredients.

I made this game using the free version of **JetBrains Rider**, coding in **C#**. This game was made to learn **Game Development** starting from the theme **"Little means a Lot"**.

Anyone can try the demo by downloading it from itch.io here: https://alexgrigore.itch.io/little-means-a-lot-a-simple-bakery-game.

You just need to download the ZIP file, unzip it and run the executable file. **(ONLY FOR WINDOWS)**

Even though this is my first project, I have tried not to use much AI. I learned from tutorials and I used AI just for explanations.
